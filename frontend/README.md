# Frontend da Magia Olivaras

O Angular usa os serviços da API local em `http://localhost:8080`. Consulte o [README do projeto](../README.md#como-rodar) para preparar o `.env`, subir a API e o banco e criar uma conta administrativa.

Neste diretório, rode `npm ci` e `npm start` para abrir a vitrine em `http://localhost:4200`. Rode `npm run build` para gerar a versão otimizada em `dist/frontend/browser/`.
